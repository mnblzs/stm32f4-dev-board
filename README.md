# stm32F4开发板7.0.1

用于 2025 赛季步兵机器人的早期 STM32F407 开发板。电源部分采用 ME3121 与 AMS1117，CAN 通信采用 SN65HVD232D。原项目说明包含缓启动、过压保护及防反接设计，具体连接和器件参数以工程原理图为准。

## 一、主要功能与硬件组成

| 项目 | 配置或用途 |
| --- | --- |
| 主控 | STM32F407 |
| 电源器件 | ME3121、AMS1117 |
| CAN 收发器 | SN65HVD232D |
| 工程版本 | 7.0.1 |

### 原理图器件与连接器索引

| 位号 | 工程标注 |
| --- | --- |
| U35 | 器件库标注 STM32F405RGT6 |
| U27 | ME3121AM6G，电源变换器件 |
| U29 | AMS1117-3.3，稳压器 |
| U18、U19 | SN65HVD232D，CAN收发器 |
| X22、X25 | 标注 CAN1，GH125 2Pin |
| X23、X24 | 标注 CAN2，GH125 2Pin |
| CN5～CN9 | GH125-S04DCA-00，4Pin |
| X20、X21 | GH125-S03DCA-00，3Pin |
| U37、U38 | XT30U-F |
| USB1 | TYPE-C 16PIN 2MD(073) |

**复刻前必须核对的版本差异：**原项目介绍称 STM32F407，但本次导出工程中 U35 的器件库料号为 STM32F405RGT6，且同位号存在多个符号单元。X1 的实例手填值为 25MHz，而库料号为 ECS-260-18-33-JGN-TR。请以实际选用芯片、晶振和连接为依据复核封装、时钟配置与固件，不能直接按项目标题采购。

## 三、复刻与使用

1. 导入工程，核对原理图、PCB版本、器件型号和封装。
2. 按原理图针号核对供电极性、信号电平及连接器插接方向；不要仅依赖线色或照片判断针序。
3. 制板前执行电气规则与PCB设计规则检查，复核板框、孔位和制造参数。
4. 焊接后先检查短路与器件方向，确认电源正常后再连接外部设备并逐项验证功能。

首次上电建议使用限流电源，依次检查电源轨、复位、下载与CAN通信。保护电路的存在不等于保护阈值、响应时间及整板可靠性已完成验证。
